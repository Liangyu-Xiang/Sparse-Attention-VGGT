rows, so a 256-Query support group has four compute blocks. Execution uses four

The old tile32 path actually used two stages regardless of config.attention_stages.
The primary ablation explicitly fixed all tiles to four warps/two stages. Both
larger tiles were slower and showed register spills. A predeclared kernel-only
screen over warps4/8 and stages1/2 selected one candidate per larger tile using
fixed-input timing and numerical tolerance checks, without test truth. The final
selection uses the fastest three-scene complete-forward mean among five fully
evaluated configurations, not the quality scores.

All 15 quality runs completed on heads/chess/stairs with 128 frames each, with
matching physical GPU per scene, exact inputs/checkpoint/preprocessing/protocol
and strict GPU monitors without overlap during GPU phases. CPU reconstruction
quality runs and GPU timing are separate. An early recorder error and an
interrupted GPU migration are preserved separately; the completed old-GPU chess
baseline remains archived but is excluded from the final paired comparison.
