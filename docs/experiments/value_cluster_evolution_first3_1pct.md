# 前三层 1% Value medoids 的区域归属与跨层簇变化

## 范围与分类方法

沿用 Chess/seq-01 第 0、20 帧，原图 640×480，VGGT 输入 518×392，
每帧 28×37 个 patch。分析前三个 global layers（L00–L02），各 16 头。
使用已有 dense 前向提取的原始 V，以及各头独立 PAM 得到的 21 个
medoids，约占两帧 2072 个 patch 的 1.0135%。特殊 token 不参与。

每个 patch 根据原始 V 的欧氏距离归到最近的 medoid，共 21 个簇。
这些区域不是空间 Voronoi 划分，也不是预定义物体类别。同簇可以跨帧、
空间不连续。渲染前用直接 FP64 向量差独立检查全部保存的归属和距离。
每个 medoid 的单独区域图中，亮区表示全部成员，其他 patch 暗化。

## 跨层比较方法

追踪的是相同帧、相同 patch 位置在前后层中的归属，而不是跨帧物体运动。
对每组相邻层比较全部 16×16 个头对，用不依赖簇编号的 ARI、NMI 衡量
完整划分的相似性。主要统计为每个源头选择下一层 ARI 最大的头，再对
16 个源头平均；允许多个源头选择同一个目标头。这是输入上的划分相似性，
不是固定的一对一功能性 head 对应。另给全头对平均及强制一对一匹配均值。

对选定头对统计完整 21×21 转移计数 C[a,b]：前层簇 a 的成员中，后层
归到簇 b 的 patch 数。桑基图带宽表示此计数，热图按源簇大小逐行归一化。
原图对照采用最大交集的 Hungarian 簇标签对齐；同色只是最优标签重排，
不表示前后层编号、medoid 或语义相同。

“明显拆分”定义：某源簇至少分到两个各占自身 ≥20% 的目标簇。
“明显合并”定义：某目标簇至少从两个各占自身 ≥20% 的源簇接收成员。
这是两个独立、固定 K=21 划分之间的成员重分配，不是层次聚类的树操作。

## 结果

| 相邻层 | 每源头最佳 ARI 均值 | 对应 NMI 均值 | 最佳簇标签对齐后相同归属比例 | 全256头对平均ARI | 强制一对一头匹配ARI |
|---|---:|---:|---:|---:|---:|
| 第1→2层 | 0.2399 | 0.4441 | 36.65% | 0.1560 | 0.1741 |
| 第2→3层 | 0.3231 | 0.5506 | 45.07% | 0.2724 | 0.2946 |

ARI=1 表示完整划分相同，约 0 表示机会水平，不能把 ARI 解释成不变 token 的百分比。
标签对齐比例仅是最优标签重排后的同归属率，不是语义保持率。

随机对照：在各帧内部置换目标层 patch 的位置，同一层 16 头使用同一置换。
因此保持每头各簇在每帧的大小、以及目标层原有头间关系；破坏其与源层位置的联系。
500 次重复，每次重新选择最佳目标头，避免将选头收益误当成跨层关系。
第1→2层随机最佳 ARI 均值 0.00109（2.5%–97.5%分位 0.00064–0.00157）；
第2→3层为 0.00100（0.00033–0.00177）。这些是随机分布分位范围，不是观测均值的置信区间。

因此这两帧上确有跨层空间划分关联，第2→3层更稳定，但远非整体簇不变。
按上述20%阈值，第1→2层每头平均 9.75/21 个源簇明显拆分、11.00/21 个
目标簇明显合并；第2→3层分别 12.31、12.25。阈值计数与整体ARI并不单调：
少数大簇稳定可提高整体成对一致性，同时更多小簇出现分流。
本实验只有同一序列两帧，选头与评估也使用相同输入，不作数据集泛化结论。

### 可直接查看的簇变化

第1层 H07 → 第2层 H02（该相邻层组最高ARI=0.365）：

- 源 C09 的 228 个 patch 中，210 个进入目标 C03，占 92.1%，是明显保留的区域。
- 源 C07 的 134 个 patch 分散到 C18（58，43.3%）、C14（30，22.4%）、
  C08（22，16.4%）、C01（18，13.4%）等，显示拆分和重组。

第2层 H12 → 第3层 H11（该相邻层组最高ARI=0.494）：

- 源 C05 的 184 个 patch 中，172 个进入目标 C07，占 93.5%。
- 源 C11 的 171 个 patch 主要进入 C20（64，37.4%）、C02（45，26.3%）、
  C12（42，24.6%），并不是作为完整簇传到下一层。

这些是便于图解的高相似头对，不能代替上面的全头平均。
