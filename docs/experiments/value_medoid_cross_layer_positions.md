# 跨层代表性 Value 的位置相似性

输入是前一实验的 Chess/seq-01 第 0、20 帧、前三个 VGGT 全局层。
直接读取已有 1% / 5% k-medoids 的 medoid patch 索引，不重新运行模型。
这里只比较同一帧内同一 patch 坐标，两个帧的坐标域分开。
这衡量原图上的空间位置一致性，不衡量 V 向量、跨帧几何对应或注意力输出误差。

逐层对每个源头与所有 16 个目标头配对，输出 1536 组头配对指标。
同编号头、所有头对、每源头独立选最佳、全局一对一最佳匹配分别汇总。
最佳一对一匹配通过最大化完全重合比例的 Hungarian assignment 获得。

指标：

- 完全重合率 = `2|A ∩ B|/(|A|+|B|)`；两集合大小相同即 `|A ∩ B|/K`。
- Jaccard = `|A ∩ B|/|A ∪ B|`，与完全重合率分别保存。
- 最近距离 = 每个源点到同帧目标点的欧氏网格距离，双向对称平均，单位 patch。
- 1 / 2 patch 内比例 = 上述双向最近距离不大于该阈值的比例。
  半径为欧氏距离，例如一格对角线距离为 sqrt(2)，不算 1 patch 内。

基线保持每头在每帧的 medoid 数量不变。固定点到均匀随机目标集合的
最近距离/邻域命中率通过无放回抽样的超几何概率精确计算。
此外进行 2000 次置换：每帧随机打乱目标层的位置，全部目标头共享该位置
置换，因此保留目标层头间重合结构和每头每帧数量，但打破跨层位置对齐。
每次置换都重新选择最佳头匹配，从而校正“事后选最佳头”产生的优势。

保留 5% 时的完全重合率：

| 层对（按第1、2、3层计） | 同编号头平均 | 最优一对一头匹配平均 | 随机位置也最优匹配 |
|---|---:|---:|---:|
| 1→2 | 7.03% | 9.74% | 8.17% |
| 1→3 | 8.95% | 13.82% | 8.07% |
| 2→3 | 8.47% | 13.82% | 8.03% |

保留 1% 时分别为 2.08% / 6.55% / 5.04%，
1.79% / 8.04% / 4.98%，2.38% / 8.04% / 4.93%。

第2→3层、5%的最优匹配下，29.96% 的代表点在另一层的某个代表点
1 patch 内，随机基线为22.21%；双向最近距离为1.995 patch，随机为2.318。
同编号头并不体现稳定的一一对应。整体结论是具有部分共享的空间位置偏好，
完全相同的 medoid 集合重用率仍然低。

进一步固定全部位置，只随机置换目标层的头编号 10000 次：6组层对/保留率
中，同编号头均未显著优于随机头编号配对（单侧 p 均大于0.05）。
该检验与随机位置基线不同，用于区分共享空间偏好和同编号头的特有对应。

该结果仅对应一个序列的两帧；置换检验以当前代表点集合为条件，
不能替代多场景重复实验，也不说明原样跨层复用这些点会保持注意力输出。
原始 p 值未经多重检验校正，图中95%区间是随机置换分布区间。

运行命令：

```bash
OPENBLAS_NUM_THREADS=4 OMP_NUM_THREADS=4 PYTHONPATH=. python scripts/analyze_value_medoid_positions.py
```

输出：`outputs/value_medoids/chess_f000000_f000020/cross_layer_positions/`，
包含逐头 CSV、最佳一对一匹配 CSV、统计 JSON、6张头配对矩阵合成热图、
随机基线比较图和原图共同位置示例。测试通过超几何组合数、随机单代表点
距离期望、禁止跨帧最近邻匹配三个独立例子校验。
